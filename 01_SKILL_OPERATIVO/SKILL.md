# Nika Media Creative Studio

Produce content as a controlled multimarca system. Treat each brand profile as independent; never transfer colors, people, claims, vehicles, logos, or tone between brands unless the user explicitly requests it.

## Start every request

1. Identify the brand, deliverable, topic, audience, language, objective, CTA, and due context from the request.
2. Read the matching brand profile:
   - EVA: `references/eva.md`
   - Janica Merchant: `references/janica-merchant.md`
   - City Kia: `references/city-kia.md`
   - Unfinished or new brands: `references/brand-registry.md`
3. Read `references/production-workflow.md` for the requested format.
4. Ask only for missing information that would materially change the result. Do not ask again for facts already present in the profile.

## Content workflow

1. Confirm factual claims. Browse current official sources for prices, laws, platform policies, vehicle years/models, news, offers, or time-sensitive facts.
2. Draft the content architecture before generation. Prefer 6-7 carousel slides unless the user requests another length.
3. Write hooks with tension and clarity. Keep explanatory copy short, visual, and useful enough to save or forward.
4. Present proposed copy when the user asks for a proposal. Generate final assets immediately when the user says `hazlo`, `crealo`, `generalos`, or equivalent.
5. Use Higgsfield when explicitly requested or already selected for the production. Otherwise use the best available image/video tool.
6. Supply reference assets for exact logos, people, locations, or products. Preserve identities and never invent a replacement model when an approved reference exists.
7. Verify every final asset for spelling, duplicated slides, repeated poses, wrong faces, wrong model years, distorted logos, cropped text, and inconsistent CTA.
8. Revise only the requested elements when the user asks for a narrow correction.

## Non-negotiable controls

- Do not expose client names or private dashboard information unless approved.
- Do not fabricate metrics, prices, dates, product features, or customer results.
- Add a concise qualifier when a strong hook intentionally simplifies a nuanced fact.
- Use exact user-approved faces. Do not beautify, age, enlarge lips, change facial geometry, or replace a real person's identity.
- For children, use only supplied or approved references and keep presentation natural and age-appropriate.
- Never generate outdated or visually similar substitute vehicles when a specific model year is requested.
- Keep social text inside safe margins and produce Instagram carousel slides in 4:5 unless instructed otherwise.

## Team request format

Accept natural language or this compact brief:

```text
Marca:
Formato:
Tema/oferta:
Objetivo:
Audiencia:
Idioma:
CTA:
Referencias nuevas:
```

If `Marca` is omitted but obvious from the request, infer it. If ambiguous, ask one focused question.
