# Modelo de recorte de personas

MediaPipe Selfie Segmenter (float16), distribuido por Google:
https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite

Integración: https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter/web_js

El modelo se sirve desde el mismo sitio y se ejecuta en el navegador. No envía la foto a un proveedor de recorte. La salida está diseñada para personas; no segmenta objetos generales.
